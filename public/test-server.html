Cómo probar el sitio web completo:

  1. Abre una terminal en la carpeta del proyecto (c:\Lavadísimo\lavadisimo-whatsapp-agent)
  2. Ejecuta el servidor: node src/server.js o haz doble clic en start-server.bat
  3. Espera a que aparezca el mensaje: "🦜 Agent escuchando en puerto 3000"
  4. Abre tu navegador y visita: http://localhost:3000
  5. ¡Listo! Ahora todas las funcionalidades (carrito, registro, pagos) deberían funcionar

Nota: Si usas "Open in Live Server" solo verás el diseño, pero las funcionalidades requieren el backend Node.js.
